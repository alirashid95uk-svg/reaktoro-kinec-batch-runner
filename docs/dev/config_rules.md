# Configuration Rules

## Scientific Values

- Do not invent scientific numeric values.
- Case values must come from supplied files, supplied data, explicit user
  instruction, or deterministic preprocessing.
- Templates must use placeholders, not fake numbers.
- Do not hide scientific defaults in Python.
- Do not use random values in examples or tests that could be mistaken for a
  scientific case.

## Three Config Layers

```text
schema_template.yaml
case_input.yaml
resolved_config.yaml
```

### `schema_template.yaml`

- Documents the accepted YAML shape.
- Contains placeholders only, not scientific values.
- Uses placeholders such as `REQUIRED`, `OPTIONAL`,
  `REQUIRED_IF_ENABLED`, `REQUIRED_IF_LOCAL_DATABASE`,
  `REQUIRED_IF_KINETICS_ENABLED`, and `TBD_SOURCE_REQUIRED`.

### `case_input.yaml`

- Is edited by the user.
- Contains real, source-supported values.
- States optional feature choices explicitly.
- Records source or provenance information where needed.

### `resolved_config.yaml`

- Is generated by deterministic preprocessing.
- Contains validated input values, normalized units, and derived quantities.
- Is stored with outputs for traceability.
- Must not be manually edited.

## Preferred Top-Level Blocks

```yaml
case:
paths:
database:
activity_models:
physical:
brine:
co2:
redox:
kinetics:
minerals:
solver:
postprocessing:
validation:
outputs:
```

Cation exchange is planned but not implemented in V1.
Experiment validation is planned but not implemented in V1.

## Field Naming

Include units in field names where practical. Acceptable names include:

```text
temperature_c
pressure_bar
water_kg
fugacity_bar
fugacity_bar
```

Use a value-and-unit structure when one fixed field-name unit is not
appropriate. Do not accept ambiguous unitless scientific quantities.

Duration and timestep control belong under `solver.timestep`, never under
`kinetics`. Fixed, adaptive, and adaptive-long-horizon modes use separate
strict schemas.

## Validation

- Reject duplicate YAML mapping keys at every nesting level.
- Reject unresolved required placeholders before preprocessing or execution.
- A schema template may be opened only as a non-runnable, unsaved YAML
  document until every sentinel is replaced explicitly.
- Reject unsupported top-level features and database sources.
- Reject contradictory feature settings.
- If a local database path fails, stop and report the exact path.
- Missing kinetic record = hard failure.
- Missing surface area for a kinetic mineral = hard failure.
- Missing thermodynamic mineral = hard failure.
- No silent skipping.
- No invented kinetic parameters.
